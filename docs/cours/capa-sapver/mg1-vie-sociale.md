# MG1 — Vie sociale

**CAPa SAPVER — 1ère année**

Agir dans son environnement social et numérique de façon responsable.

-   :material-email-outline:{ .lg .middle } <span class="zt-step">7</span> **Écrire un courriel professionnel**

    ---

-   :material-cart-outline:{ .lg .middle } <span class="zt-step">8</span> **Acheter en ligne sans se faire avoir**

    [:octicons-arrow-right-24: Ouvrir l'activité](activites/sq08-achats-en-ligne.md)

-   :material-human-wheelchair:{ .lg .middle } <span class="zt-step">9</span> **Un numérique accessible à tous**
