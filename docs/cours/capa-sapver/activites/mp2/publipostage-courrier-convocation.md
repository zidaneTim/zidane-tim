# 📨 Réaliser un publipostage de courriers de convocation

## Objectifs pédagogiques



<div class="zt-objectifs" markdown>

- Réaliser un publipostage simple (courrier de convocation fusionné) à partir d'une lettre type et d'une source de
  données destinataires
- Vérifier les données fusionnées avant tout envoi réel

</div>

## Contexte et problématique



Tu es agent du **SAAD de Loudéac**. Chaque année, le service organise une réunion d'information pour les familles
des bénéficiaires. Ta responsable de secteur te confie l'envoi des courriers de convocation à cinq familles : plutôt
que de retaper cinq fois la même lettre, elle te demande d'utiliser le publipostage.

!!! question "Problématique"
    « Comment produire cinq courriers de convocation personnalisés à partir d'une seule lettre type et d'une liste
    de destinataires ? »

## Travail à faire



**Créer la source de données et fusionner le courrier**

1. Créer, dans un tableur, une source de données destinataires (5 familles fictives) avec les colonnes : *Civilité*,
   *Nom*, *Prénom*, *Adresse*, *Code postal*, *Ville*, *Nom du bénéficiaire suivi*.
2. Rédiger la lettre type de convocation dans le traitement de texte : en-tête du SAAD, objet, date et lieu de la
   réunion, corps du texte personnalisable, formule de politesse.
3. Lancer le publipostage (fonction *Publipostage* du traitement de texte), relier la lettre type à la source de
   données créée à l'étape 1.
4. Insérer les champs de fusion aux bons endroits du texte (adresse complète en en-tête, civilité et nom dans la
   formule d'appel, nom du bénéficiaire suivi dans le corps du texte).
5. Lancer un aperçu des résultats fusionnés et vérifier, sur les 5 lettres, qu'aucun champ n'est resté vide et
   qu'aucune donnée n'est mal alignée (ex. civilité manquante, adresse tronquée).
6. Fusionner vers un nouveau document regroupant les 5 courriers personnalisés.

!!! tip "Astuce"
    Avant de lancer la fusion finale, vérifier toujours la première ET la dernière ligne de la source de données :
    ce sont les deux lignes où une erreur de copier-coller passe le plus souvent inaperçue.

**Questions de synthèse**

- Pourquoi vérifie-t-on systématiquement l'aperçu des résultats fusionnés avant l'impression ou l'envoi réel ?
- Quel gain de temps le publipostage apporte-t-il par rapport à la rédaction individuelle de chaque courrier ?

??? tip "Vérifier mes réponses"
    - Une erreur dans la source de données (champ vide, faute de frappe) se répercute automatiquement sur tous les
      courriers fusionnés ; la vérification de l'aperçu évite d'envoyer des courriers erronés à des familles.
    - Le publipostage évite de retaper cinq fois la même lettre : un seul modèle et une seule source de données
      suffisent à produire tous les courriers personnalisés en quelques clics.

!!! tip "Où répondre ?"
    Dépose ta source de données, ta lettre type et le document fusionné final dans ton bloc-notes **OneNote**,
    section *MP2 — Communication professionnelle*.

## Ressources et outils



- **Traitement de texte (Word)** : fonction *Publipostage* (onglet *Publipostage* → *Démarrer la fusion et le
  publipostage*).
- **Tableur (Excel)** : pour la source de données destinataires.

## Compétences CRCN et parcours Pix

- **CRCN 4.2.7** — Publipostage.

## Grille d'évaluation



<div class="zt-grille" markdown>

| Critère | Indicateurs observables | Niveau |
|---|---|---|
| Source de données (4.2.7) | Les 5 lignes de destinataires sont complètes et cohérentes. | Insatisfaisant / À consolider / Satisfaisant / Très satisfaisant |
| Fusion et champs | Les champs de fusion sont correctement placés ; l'aperçu des 5 lettres est vérifié sans erreur. | Insatisfaisant / À consolider / Satisfaisant / Très satisfaisant |
| Présentation du courrier | La lettre type respecte les codes d'un courrier professionnel (en-tête, objet, politesse). | Insatisfaisant / À consolider / Satisfaisant / Très satisfaisant |
